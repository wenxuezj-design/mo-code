# 路径边界采用分层权限优先级

路径边界加入后的裁决顺序为：灾难删除熔断、`bypassPermissions`、显式 `deny`、`plan` 硬拒绝、文件系统访问未知、真实路径无法可靠解析或保护路径写入、显式 `ask`、显式 `allow`、普通外部路径，最后才是权限模式和 Shell 语义的默认行为。

因此，保护路径、未知文件访问和无法解析的真实路径不能被普通 `allow` 或授权记忆跳过；普通外部路径可以通过显式 `allow` 预先授权；`bypassPermissions` 跳过这些普通边界但不能跳过灾难删除熔断。路径边界产生的确认不可记忆，`dontAsk` 遇到这些确认时改为拒绝。
