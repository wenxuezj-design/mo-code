# Shell 持久授权只匹配精确命令

用户从确认界面创建 Shell 持久授权时，mo-code 保存并匹配完整命令，不自动生成前缀或通配规则。Claude Code 会为命令生成可复用的权限规则，但在本项目的快速复现阶段，自动扩大匹配范围容易产生用户没有明确同意的权限；需要更宽范围时，用户仍可在权限配置中手动编写规则。

这一决定以重复询问部分命令变体为代价，换取授权含义明确、实现简单以及默认不扩大权限。未来若引入命令规则建议，需要把它作为新的显式设计，并处理已有持久授权的兼容问题。

自动生成规则时，命令中的 `*` 和反斜杠必须转义：未转义的 `*` 继续表示用户手写的权限通配符，转义后的 `\*` 才表示 Shell 命令中的普通星号。这样生成的规则仍可写入现有 `permissions.allow`，而不会把精确授权意外扩大成通配授权。
