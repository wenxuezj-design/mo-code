# 漫画网页排字工具设计

## 背景

mo-code 技术科普漫画预计包含约 13 个连续章节。漫画页面由图像模型生成黑白无字底图，人物对白、旁白和技术文本需要准确地覆盖到气泡与旁白框中。

图像模型不适合直接生成中文文字：文字容易出现错字或乱码，而且修改一句对白可能导致整页画面被重新解释。因此，漫画底图与文字必须分层管理。

排字流程还应尽量减少人工操作。用户负责审核和必要的视觉微调，Codex 负责生成底图、初次排字、浏览器检查、上传确认后的底图和最终本地导出。

## 目标

- 在本地网页中加载漫画无字底图。
- 从章节脚本导入或录入每页台词。
- 将每段文字作为独立、可移动、可缩放的图层叠加在底图上。
- 支持横排中文、竖排中文、旁白和技术文本样式。
- 自动适配字号与换行，并检测文字溢出。
- 将布局自动保存为可版本控制的 JSON。
- 不打开文件选择器，直接导出到 story worktree 的约定路径。
- 允许 Codex 通过浏览器完成排字，通过命令完成最终验证与本地导出；只有确认后的底图进入云盘。

## 非目标

首版不实现以下能力：

- 自动识别图片中的气泡或旁白框；
- OCR；
- 自动生成、修改或删除气泡；
- 任意文件系统路径读写；
- 多人实时协作；
- 在网页服务器中直接保存 Google Drive 凭据或调用云盘 API；
- 完整漫画绘图、修图或图层编辑功能。

气泡位置由 Codex 在浏览器中逐个点击和调整。相比计算机视觉识别，这个流程更稳定，也已足以把用户的人工参与降低到审核与少量微调。

## 使用流程

1. Codex 根据 `script.md` 生成一页无字漫画底图。
2. 底图经确认后以不可变版本名上传云盘，并把哈希、字节数、尺寸和远端路径写入章节 `assets.json`。
3. 底图由清单回拉并验证到 `.story-assets/cache/<chapter>/`。
4. Codex 为当前页创建初始台词布局 JSON。
5. 本地服务器打开排字网页。
6. Codex 在浏览器中依次选择台词、定位气泡并调整文字区域。
7. 用户可以直接在网页中拖动、缩放或修改文字。
8. 所有变化自动保存到当前页的 JSON 文件。
9. 用户确认后，Codex 或网页按钮触发固定路径导出。
10. PNG 与 WebP 成品写入被 Git 忽略的 `.story-assets/exports/`，不上传 Google Drive；修改脚本或布局后按需重新生成。
11. Codex 检查文字溢出、输出尺寸、文件体积和 Git 状态。

## 页面布局数据

布局使用原图像素坐标，而不是浏览器显示后的 CSS 坐标。页面缩放只影响显示，不改变保存值和最终导出结果。

```json
{
  "version": 1,
  "chapter": "01-agent-loop",
  "page": "01",
  "source": {
    "file": "page-01-base.webp",
    "width": 864,
    "height": 1821
  },
  "items": [
    {
      "id": "N02",
      "type": "narration",
      "speaker": null,
      "text": "她常请人工智能帮她回答问题。",
      "direction": "vertical",
      "x": 458,
      "y": 1120,
      "width": 116,
      "height": 238,
      "padding": 12,
      "fontFamily": "PingFang SC",
      "fontSize": 28,
      "fontWeight": 600,
      "lineHeight": 1.35
    }
  ]
}
```

每个文字区域独立保存宽高，不要求气泡或旁白框具有相同尺寸。

## 编辑交互

### 选择和移动

- 点击右侧台词列表或画面文字即可选中。
- 选中区域显示边界、编号和控制点。
- 在区域内部拖动，更新 `x` 与 `y`。

### 调整宽高

选中区域提供八个控制点：

- 四个角同时调整宽度与高度；
- 左右边调整宽度；
- 上下边调整高度。

尺寸调整写回原图坐标。区域最小尺寸受到限制，不能缩小到无法操作。

### 文字编辑

- 双击文字区域可直接修改内容。
- 右侧面板可切换横排或竖排。
- 支持字号、行高、字重、内部边距和对齐方式。
- 普通对白、旁白和技术文本使用独立样式预设。

### 自动适配

自动适配只修改字号和换行，不改变用户划定的文字区域：

1. 从当前字号开始排版；
2. 如果文本溢出，逐步缩小字号；
3. 到达允许的最小字号仍溢出时，显示错误；
4. 不自动扩大区域或遮挡画面内容。

### 溢出检查

工具持续检查所有文字区域：

- 超出宽度或高度；
- 小于最小字号；
- 文字区域超出页面；
- 文本为空；
- 同一区域编号重复。

问题项目在右侧列表和页面上同时标红。

## 排版规则

默认使用横排中文，保证 README 在线阅读和技术内容的可读性。以下情况可以使用竖排：

- 睦的关键登场对白；
- 角色独白；
- 祥子的中二宣言；
- 窄而高的旁白框。

代码、终端输出、文件名和协议名称始终使用横排等宽字体。

## 自动保存

正式工具不以 `localStorage` 作为事实来源。编辑状态在短暂防抖后写入页面 JSON：

```text
PUT /api/pages/01-agent-loop/01/layout
```

保存过程：

1. 前端发送完整布局；
2. 服务器验证版本、章节名、页码、坐标和文本字段；
3. 写入同目录临时文件；
4. 原子替换 `page-01-lettering.json`；
5. 返回新版本摘要；
6. 页面显示“已保存”。

保存失败时保留浏览器内当前状态，显示错误并允许重试。

## 导出

### 浏览器导出流程

排字层采用 SVG 编辑。导出时使用原图尺寸创建离屏画布：

1. 绘制原始漫画底图；
2. 按原图坐标渲染所有 SVG 文字；
3. 生成 WebP 和 PNG 二进制；
4. 将文件发送给本地服务器；
5. 服务器写入约定路径。

导出按钮不会弹出系统文件选择器。

### 固定输出路径

WebP：

```text
.story-assets/exports/<chapter>/pages/page-<page>-final.webp
```

PNG：

```text
.story-assets/exports/<chapter>/pages/page-<page>-final.png
```

成品可以从底图与布局 JSON 重建，不进入 Git、章节底图清单或 Google Drive。网页服务器只把它们写入本机 exports 目录，也不持有云盘认证信息。

### Codex 代为导出

用户人工调整后，只需说明“第 1 页可以导出”。Codex 将：

1. 读取已保存的布局；
2. 触发或运行同一导出流程；
3. 验证 WebP 和 PNG；
4. 报告本地输出路径。

用户不需要选择路径、移动文件或手动上传。

## 本地服务器与安全边界

- 默认只监听 `127.0.0.1`。
- 只允许读取清单指定的 `.story-assets/cache/` 底图，并读写 `docs/story/chapters/` 下的布局 JSON 与 `.story-assets/exports/` 下的成品。
- 章节名和页码必须满足限定格式。
- 所有解析后的路径必须位于允许的根目录内。
- 拒绝 `..`、绝对路径、符号链接逃逸和任意输出路径。
- 限制 JSON 与图片请求体大小。
- JSON 使用原子写入，避免保存中断造成损坏。
- 导出不得覆盖漫画底图。

## 组件边界

### `server.mjs`

负责静态资源、页面发现、布局读写和固定路径导出。它不负责排版计算，也不接触云盘。

### `layout.mjs`

负责原图坐标与显示坐标之间的转换、拖动和缩放约束。

### `text-fit.mjs`

负责横排、竖排、换行、字号适配和溢出判断，不读取或写入文件。

### `canvas-export.mjs`

将底图与当前 SVG 文字层合成为原图尺寸的 PNG/WebP，并把二进制交给服务器。

### 页面数据

`page-*-lettering.json` 是排字事实来源。更换界面或导出实现时，已有台词布局仍可复用。

## 错误处理

- 底图不存在：禁止编辑与导出，并显示期望路径。
- 底图尺寸与 JSON 不一致：要求显式迁移布局，不静默缩放。
- 字体不可用：工具不会检测或显示缺失警告；浏览器按当前系统字体回退，可能改变换行与导出像素。正式导出限制与跨电脑要求见 `docs/story/README.md` 的“字体限制”。
- 自动适配失败：保持原区域，标记溢出，不删除文字。
- 保存失败：保留浏览器状态并允许重试。
- 导出失败：保留布局和临时输出，不覆盖已有成品。
- 同名成品已存在：导出前创建新临时文件，成功后原子替换。

## 测试策略

### 单元测试

- 原图坐标与显示坐标双向转换；
- 八方向缩放约束；
- 横排换行与字号适配；
- 竖排字符布局；
- 溢出判断；
- 布局 JSON 校验；
- 路径穿越和非法章节名拒绝。

### 集成测试

- 读取现有页面与布局；
- 自动保存产生合法 JSON；
- 保存采用原子替换；
- WebP 与 PNG 写入正确目录；
- 导出尺寸与底图一致；
- 服务器不能写出允许目录。

### 浏览器验收

- 选择、拖动和八方向缩放文字框；
- 横竖排切换；
- 自动适配和溢出提示；
- 刷新后恢复保存布局；
- 不出现文件选择器；
- Codex 可以通过浏览器完成一整页排字。

## 首版验收标准

- 可加载第一章第 1 页无字底图；
- 可编辑五段现有台词；
- 每段文字可以独立移动和缩放；
- 预览与最终导出位置一致；
- 布局自动保存到 `page-01-lettering.json`；
- WebP 与 PNG 自动写入约定路径；
- 所有测试通过；
- 用户不需要手动选择文件路径或上传 PNG。
