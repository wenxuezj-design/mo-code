# 漫画网页排字工具

跨电脑安装、底图同步、启动命令和导出路径统一见[漫画跨电脑工作流](../../README.md)。本文只说明浏览器中的编辑操作。

## 打开与换页

编辑器启动后默认显示 `01-agent-loop` 第 1 页。页面由 URL 查询参数选择，例如：

```text
http://127.0.0.1:41731/?chapter=01-agent-loop&page=02
```

换页时修改二位 `page` 参数并刷新。若页面提示底图未缓存，按顶层指南拉取该页后再刷新。

## 编辑

- 点击画面区域或右侧台词选中项目。
- 拖动选中区域内部可移动位置；拖动八个控制点可独立改变宽高。
- 右侧可修改文字、横竖排、字号与内部边距。
- “自动适配”只缩小字号，不改变用户划定的区域。
- “隐藏辅助线”只影响编辑界面，不进入导出。

坐标始终使用原图像素；浏览器显示缩放不会改变保存值或导出位置。修改停止约 400 ms 后自动保存，离开页面前确认右上角显示“已保存”。

## 检查与浏览器导出

“检查溢出”会同时标红画面区域和右侧台词。存在溢出时，扩大区域、调整边距或使用“自动适配”；工具会阻止带溢出的导出。

“生成 PNG”和“生成 WebP”会先保存当前布局，再把成品写入顶层指南约定的本地 exports 目录，不会打开文件选择器。按钮失败时已有成品与布局不会被部分文件覆盖；修正页面后可以直接重试。

保存失败时浏览器保留当前内存状态。不要刷新，先恢复本地服务器，再做一次修改触发自动保存。
