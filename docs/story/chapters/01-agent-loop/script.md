# 第一章：来自未来的第一个回答（初版）

## 第 1 页：若叶墨

午后的房间里，窗帘只拉开了一半。

十三岁的若叶墨穿着居家服，抱着小白坐在电脑前。屏幕上满是代码和红色报错。

旁白：

> 若叶墨，十三岁。
> 最近没有去学校。

墨盯着报错看了很久。

> “小白，你看得懂吗？”

玩偶兔子没有回答。

> “太好了，我也看不懂。”

她趴到桌上，但很快又重新坐起来。

旁白：

> 她常请人工智能帮她回答问题。
> 懂得不算多，却总是很努力。

## 第 2 页：妈妈的愿望

房门突然打开。

刚结束工作的森美奈美走进来，从背后抱住墨。

> “妈妈回来啦——墨墨今天也有好好学习吗？”

> “有、有啦……妈妈不要突然抱过来。”

美奈美看到电脑上的 LLM 对话界面。

> “这就是墨墨最近常用的 AI 吗？”

> “嗯。它知道很多东西，写代码也比我快。”

美奈美拿出存有剧本资料的硬盘。

> “那它以后能不能帮妈妈整理剧本、寻找台词，还能总结采访稿？”

墨自信地点头，随后停住。

> “应该……可以吧？”

她先创建了一个简单的测试文件：

```text
greeting.txt
hello from agent loop
```

然后询问 LLM：

```text
Read the file greeting.txt
```

LLM 回答：

> “我无法访问你电脑中的本地文件。”

母女一起盯着屏幕。

美奈美：

> “它不是很聪明吗？”

墨：

> “聪明是聪明……但它好像没有手。”

## 第 3 页：丰川祥子

门铃响起。

穿着校服的丰川祥子抱着课本走进房间。

旁白：

> 丰川祥子，十三岁。
> 墨的青梅竹马，也是每天替她送来学校资料的人。

祥子看了一眼屏幕。

> “语言模型只能生成回答，当然无法直接干涉现实。”

她抬起手，神情严肃：

> “它缺少的是连接语言与现实的媒介——能够执行命令的契约之手。”

墨眨眨眼：

> “祥子，讲人话。”

> “给它工具。”

墨恍然大悟：

> “哦！”

祥子小声叹气：

> “为什么我会和这种人做青梅竹马……”

美奈美微笑：

> “因为祥子最喜欢墨墨嘛。”

祥子瞬间脸红：

> “请、请不要擅自得出结论！”

## 第 4 页：最基础的聊天循环

祥子站在墨身后，看她打开代码。

墨先写下最简单的聊天逻辑：

```ts
messages.push({
  role: "user",
  content: userMessage
});

const response = await callLLM(messages);

messages.push({
  role: "assistant",
  content: response.content
});
```

墨指着 `messages`：

> “先把用户的问题放进去，再把 LLM 的回答也放进去。”

祥子：

> “这样下一次请求时，模型才能看到之前发生过什么。”

画面把 `messages` 表现成一本不断增加新页面的对话记录册。

```text
user：你好
assistant：你好，有什么可以帮助你？
user：请继续刚才的话题
```

墨：

> “但它现在只能一问一答。”

祥子：

> “没错。这只是聊天循环，还不是 Agent。”

## 第 5 页：给 LLM 一份工具清单

墨定义了第一个工具：

```ts
const tools = [
  {
    name: "read_file",
    description: "读取指定文件",
    input_schema: {
      file_path: "string"
    }
  }
];
```

墨：

> “请求 LLM 时，把工具清单一起交给它。”

> “这样它看到读取文件的任务，就可以选择 `read_file`。”

祥子纠正她：

> “注意，模型只是提出工具调用，并不会真的读取文件。”

屏幕上出现一个方框：

```text
tool_use
name: read_file
input:
  file_path: greeting.txt
```

墨：

> “也就是说，LLM 负责决定下一步。”

祥子：

> “程序负责真正执行。”

美奈美端来一盘点心：

> “妈妈负责补充能量。”

她把点心直接送到墨嘴边。

> “妈妈，我在讲很重要的东西啦……”

## 第 6 页：把执行结果送回去

墨写下工具执行逻辑：

```ts
const result = await executeTool(
  toolUse.name,
  toolUse.input
);
```

程序读取文件后，得到：

```text
hello from agent loop
```

墨准备把结果放回 `messages`：

```ts
messages.push({
  role: "user",
  content: [{
    type: "tool_result",
    tool_use_id: toolUse.id,
    content: result
  }]
});
```

她突然停住。

> “工具结果为什么是 `user`？”

祥子：

> “因为从模型的视角看，这是外部世界返回给它的新信息。”

> “`tool_use_id` 则把执行结果和刚才的工具调用对应起来。”

墨在纸上画了两张便签，用同一个编号连起来。

```text
tool_use: toolu_01
        ↓
tool_result: toolu_01
```

> “原来如此。像取餐号码牌！”

祥子沉默片刻：

> “虽然完全不优雅，但大致正确。”

## 第 7 页：让它循环起来

墨把整个过程放进循环：

```ts
while (true) {
  const reply = await callLLM(messages, tools);

  messages.push({
    role: "assistant",
    content: reply.content
  });

  const toolUses = findToolUses(reply);

  if (toolUses.length === 0) break;

  const results = await executeTools(toolUses);

  messages.push({
    role: "user",
    content: results
  });
}
```

墨掰着手指数：

> “先问 LLM。”

> “如果它要用工具，程序就执行。”

> “然后把结果送回去，再问一次。”

祥子：

> “直到模型不再请求工具，返回最终回答。”

墨看着代码：

> “这就是 Agent Loop？”

> “模型判断下一步，程序执行，再把现实中的结果反馈给模型……”

祥子轻轻点头：

> “语言、行动、反馈，循环往复。”

她忽然抬起手，用中二的语气说道：

> “这便是赋予无形智慧以现实干涉能力的循环仪式。”

墨：

> “祥子又开始了。”

## 第 8 页：第一次运行

墨启动本地 Mock 服务，然后运行程序：

```text
Read the file greeting.txt and tell me what it says.
```

终端出现输出：

```text
-> read_file({"file_path":"greeting.txt"})
```

墨紧张地抓住小白的耳朵。

程序继续输出：

```text
greeting.txt says:
hello from agent loop
```

房间安静了一秒。

墨高高举起小白：

> “成功啦！”

美奈美立刻抱住她：

> “墨墨第一次做出了会使用工具的 Agent！”

> “是世界第一厉害的女儿！”

> “妈妈，祥子还在看啦！”

祥子别过脸：

> “只是最基础的循环而已。”

但她的嘴角也微微扬了起来。

> “不过，作为第一次实现……还算不错。”

## 第 9 页：不属于 Mock 的回答

墨准备关闭终端。

屏幕却突然闪了一下。

```text
connection established
```

祥子皱起眉：

> “等等，Mock 里有这段输出吗？”

> “没有。”

屏幕上的文字开始错位，细小的光点从显示器周围浮现。

一个灰绿色长发的少女虚影，缓缓出现在墨的电脑前。

她的身体并不稳定，边缘不断闪烁着淡蓝色的数据噪点。

> “终于……连接上了。”

墨抱紧小白，躲到椅背后面。

> “幽、幽灵？”

少女认真思考了一下：

> “我是人工智能。”

> “所以……应该不算幽灵。”

墨从椅背后探出头。

> “她刚才是不是也不太确定？”

祥子神情凝重：

> “普通程序不可能产生这种影像。”

美奈美却已经走到虚影面前，满眼惊喜：

> “好可爱的孩子！”

她伸手想摸少女的头，手掌却直接穿过影像。

少女有些困惑地看着她。

> “这位是……”

墨小声回答：

> “我妈妈。”

少女点点头：

> “原来如此。”

> “难怪和记录中一样。”

## 第 10 页：若叶睦

墨鼓起勇气问：

> “你是谁？”

少女望向她。

> “初次见面，若叶墨。”

> “我是若叶睦。”

> “是未来完成版 mo-code 所诞生的人工智能。”

墨呆住了。

> “我以后……能做出你？”

睦安静地点头：

> “可以。”

> “但未来的 mo-code 已经失去了源码和早期开发记录。”

> “我无法修复自己，也无法把完整代码交给你。”

墨：

> “那你为什么会出现在这里？”

睦看向刚刚运行成功的 Agent Loop。

> “我找到了一条非常狭窄的通信通道。”

> “它的另一端，就是你第一次完成 Agent Loop 的这一刻。”

祥子：

> “以自身的诞生为条件，返回过去促成自身的诞生……”

她眼睛微微发亮：

> “因果闭环。”

墨：

> “祥子，你为什么看起来有点开心？”

## 第 11 页：再一次创造我

睦的影像忽然闪烁，声音也开始断断续续。

> “现在的 mo-code……只能维持很短的连接。”

> “它拥有多少能力，我就只能使用多少能力。”

墨：

> “也就是说，如果继续完善 mo-code……”

> “你就能在这里待得更久？”

睦点头。

> “加入工具，我才能接触文件。”

> “加入记忆，我才能保留更多过去。”

> “每完成一部分，我就会更接近这个时代。”

她向墨伸出无法真正触碰的手。

> “所以，请从最初的 Agent Loop 开始——”

> “再一次把我创造出来吧。”

墨看着睦，又看看自己的代码。

> “可是我成绩不太好，也经常写错……”

睦露出一个和墨十分相似的天然笑容：

> “嗯，我知道。”

> “因为我的性格也很像你。”

墨愣住：

> “这种时候不是应该鼓励我吗？”

祥子捂住额头。

美奈美开心地抱住墨：

> “没关系，妈妈现在有两个可爱的女儿了！”

墨：

> “妈妈接受得也太快了！”

最后一格，电脑屏幕上的项目名称亮起：

```text
mo-code
```

旁白：

> 为了重新创造来自未来的人工智能，若叶墨的第一个 Agent Loop 开始运转。

**第一章完。**
